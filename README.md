# Osmo Cast

Osmo Cast is an Android app designed for **DJI gimbals**, enabling wireless screen sharing and remote gimbal control using two phones. It is primarily intended for the DJI Osmo Mobile SE.

Install Osmo Cast on both phones:

- **Caster phone:** Mounted on the gimbal, it streams its screen to the receiver over Wi-Fi using WebRTC.
- **Receiver phone:** Connects to the caster phone over Wi-Fi, receives the live screen feed, and provides an on-screen D-pad to control the DJI gimbal.

### How It Works

- **Video streaming:** The caster transmits its screen to the receiver over Wi-Fi.
- **Gimbal control:** The receiver connects to the DJI gimbal via Bluetooth and uses the D-pad to control its movement.
- **Two-phone setup:** One phone transmits the screen, while the other receives the live feed and controls the gimbal.

**Video streaming uses Wi-Fi; DJI gimbal control uses Bluetooth.**
